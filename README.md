# PV-Planung – Dachbelegung & Material

Offline-fähige PWA für den Dachdecker Meisterbetrieb Mette: PV-Projekte im
Kalender planen, Dachflächen maßstabsgetreu mit Modulen belegen (einzelne
Plätze z. B. für Dachfenster abwählbar, kWp-Berechnung) und die
Material-Checkliste abhaken. Alle Daten bleiben im Gerätespeicher.

## Am Handy nutzen

1. `https://fastsniperassasin-wq.github.io/PV-Manager-/` in Chrome öffnen
2. Menü ⋮ → „App installieren“

## Entwicklung

```
npm install
npm run dev
npm test
npm run build
```

Deployment: GitHub Action baut und veröffentlicht bei jedem Push auf `main`
(GitHub Pages, Quelle „GitHub Actions“).
